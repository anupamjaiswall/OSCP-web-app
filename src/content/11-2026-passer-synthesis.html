🗺️ 21.1 Map Before You Commit

[PASSER:2026] [TIME:ROTATE] [ENUM:NMAP]

  • Run clean discovery across every recorded target before deeply committing to the first promising clue.
  • Separate open-port discovery from targeted fingerprinting. Confirm what is open first, then spend version/script time on those ports.
  • Write every plausible lead before exploitation. Rank leads by evidence + prerequisite completeness + shortest likely path.
  • Do not treat the first suspicious service/version as the answer. Finish the service map first.

↺ 21.2 Fresh-Eyes Reset — Re-enumerate From Zero

[PASSER:2026] [STUCK:RESET] [OUTPUT:TRIAGE]

A repeated 2026 pattern: when progress stopped, the breakthrough often came after stepping away, rotating, or rebuilding the target model from the beginning.

FRESH-EYES RESET
1. Bank any earned proof first.
2. Re-read raw scan output from line one.
3. Touch every open service manually.
4. Re-check exact tool errors / status codes.
5. Re-run hostname / vhost / redirect / TLS-name discovery.
6. If authenticated, enumerate the service from the inside.
7. Re-run credential/material fan-out with local-vs-domain context explicit.
8. If shell exists, re-enumerate identity, privileges, listeners, services/tasks and configs.
9. If AD, restart at domain/DC/DNS/time and rebuild the graph from current credentials.
10. Write the exact evidence required to return to any parked hypothesis.

One bounded evidence-producing retry is useful. Repeating the same hypothesis with a different tool is usually not.

🔎 21.3 Enumeration Means “Inside the Service,” Not Just a Banner

[PASSER:2026] [ENUM:DEPTH] [CREDS:FANOUT]

  • FTP: connect; list recursively where appropriate; inspect names, backups, configs and writable areas.
  • SMB: shares, readable files, writable shares, users/groups, sessions/logged-on users and scope of the credential.
  • Web: hostnames/vhosts, TLS names, source/JS/API, files/backups, auth/reset/session behavior, parameters and uploads.
  • Database: what can the current login actually read/write/execute; enumerate databases, permissions, linked/adjacent functionality and stored secrets/configs.
  • Unknown port: banner/connect manually first; identify protocol before searching for exploits.
  • Post-shell: manually establish identity, privileges, processes/listeners, services/tasks and unusual files before relying on bulk helper output.

Recent passers repeatedly described missed output and incomplete service enumeration as bigger time sinks than lack of exotic exploits.

🏰 21.4 AD Restart Loop — Context → Identity → Graph → New Material → Repeat

[PASSER:2026] [AD:FLOW] [PIVOT:FLOW]

DOMAIN / DC / DNS / TIME
        ↓
SMB + LDAP visibility / shares / users / groups / computers
        ↓
AS-REP / SPNs / password policy / sessions / local-admin rights
        ↓
BloodHound / ACL / delegation / other evidence-backed edges
        ↓
foothold / lateral movement / local privesc
        ↓
new password / hash / key / ticket / config / route
        ↓
RE-RUN visibility + graph with the NEW context

Do not let a working pivot become an assumption. Prove route → destination IP reachability → listener binding → DNS separately. Treat each newly reachable internal host as a fresh enumeration problem.

🧠 21.5 Breaks, Rotation & Reproduction

[PASSER:2026] [TIME:ROTATE] [EVIDENCE:PACKET]

  • Breaks are part of exam operations, not lost time. OffSec's current guide explicitly says the exam window accounts for rest, food, drink and sleep.
  • Community timeboxes vary. Treat them as safety rails, not rules. Rotate when evidence stops improving; stay while a path is producing concrete new facts.
  • Before leaving a compromised target, make sure the path is reproducible from notes without relying on memory.
  • When a passing score looks likely, protecting screenshots, proof submissions, commands, exploit sources and report reproducibility can be higher value than chasing optional points.
BEFORE ROTATING FROM A COMPROMISED TARGET
[ ] earned proof banked correctly
[ ] exact initial-access command/request recorded
[ ] exact privilege-escalation prerequisite + trigger recorded
[ ] exploit source URL / modified-code delta preserved
[ ] screenshots readable and mapped to the target
[ ] current notes can reproduce the compromise step-by-step
[ ] return trigger written for anything unfinished
📚 21.6 What Recent Pass Reports Repeated

[PASSER:2026]
