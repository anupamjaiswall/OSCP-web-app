20. PENELOPE SHELL HANDLER — CONSERVATIVE OSCP MODE

[SHELL:PENELOPE] [SHELL:LISTENER] [OSCP:SAFE]

Exam rule first: OffSec does not maintain a whitelist for every third-party tool. The current OSCP+ rule is that tools are acceptable only when the action they perform is not restricted. A tool can still become disallowed if you use a feature that performs a restricted action. Penelope upstream provides -O / --oscp-safe specifically to reduce the chance of using risky modules/features. Verify the current OffSec Exam Guide/FAQ on exam day.

Conservative reverse-shell listener

# Check that your installed Penelope exposes OSCP-safe mode
penelope -h | grep -E -- '--oscp-safe|-O'

# Preferred exam listener: bind to the VPN interface and enable OSCP-safe mode
penelope -O -i tun0 -p $LPORT

# Example with a fixed port
penelope -O -i tun0 -p 4444

# More netcat-like behavior: also disable automatic shell upgrade
penelope -O -U -i tun0 -p $LPORT

If your installed build does not show -O / --oscp-safe, do not assume an older version has the same protections. Either update to a version that documents the switch or fall back to the simple listener already in these notes:

rlwrap -cAr nc -nvlp $LPORT

Exam guardrails

  • Do not use Penelope's --mcp mode during OSCP. The current OSCP+ exam prohibits AI chatbot/LLM assistance; the upstream MCP feature is designed to let external clients drive live sessions.
  • Do not use automatic privilege-escalation modules. Penelope's upstream documentation specifically warns about modules such as traitor, which performs automatic privilege escalation.
  • Meterpreter restrictions still apply separately. Penelope does not remove OffSec's one-target restriction for Meterpreter/Metasploit restricted functionality.
  • Keep exploitation decisions manual and evidence-driven. A shell handler should handle the shell; it should not choose or automatically execute an exploit path for you.

Quick choice during the exam

Need the simplest possible listener?
  → rlwrap -cAr nc -nvlp $LPORT

Want PTY/session handling but still conservative?
  → penelope -O -i tun0 -p $LPORT

Need an automated module / privilege escalation / AI-driven session control?
  → STOP. Re-check the official exam rules before using that feature.
