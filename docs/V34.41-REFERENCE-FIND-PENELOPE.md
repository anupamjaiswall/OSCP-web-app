# V34.41 — Reference Find + Penelope

Date: 2026-10-02

## Whole-reference find

The Full Reference now gets a dedicated find bar inside its navigator. Opening a Global Search result carries the current query into Full Reference and:

- highlights every literal occurrence of the query in the hydrated offline reference;
- shows `current / total` match count;
- provides **Prev**, **Next**, and **Clear** controls;
- supports **Enter** for next and **Shift+Enter** for previous while the find box is focused;
- automatically opens every collapsed ancestor `<details>` containing the active match;
- keeps the existing section-level Previous/Next navigator separate from keyword-level Previous/Next navigation.

The existing `subdomain → 2.2 /etc/hosts Management` search regression remains relevant; the new find controller additionally verifies nested collapsed matches are revealed.

## Penelope shell handler

Added an offline reference section for Penelope with the conservative listener form:

```bash
penelope -O -i tun0 -p $LPORT
```

`-O / --oscp-safe` is an upstream Penelope feature intended to reduce accidental use of OSCP-risky functionality. This is not an OffSec whitelist entry: the official OSCP+ rule remains action/feature based. Restricted actions stay restricted even when a tool itself is otherwise acceptable.

The reference explicitly advises against Penelope MCP/AI-driven session control during OSCP and against automatic privilege-escalation modules such as `traitor`. Meterpreter/Metasploit restrictions remain separate.

Rule sources checked 2026-10-02: OffSec OSCP+ Exam Guide and OSCP+ Exam FAQ. Tool behavior source: `brightio/penelope` upstream documentation.
